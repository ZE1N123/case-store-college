# CASE ROOM — учебный магазин кейсов

Учебный сайт на ASP.NET Core 8: витрина кейсов, регистрация и вход, корзина и история заказов, блог с фотографиями и видео, панель администратора и переключатель дневной/ночной темы. Данные каталога, аккаунтов, настроек и публикаций хранятся в `App_Data/store.json`, загруженные медиафайлы — в `wwwroot/uploads`.

## Запуск

1. Установите .NET 8 SDK.
2. Откройте PowerShell в папке проекта.
3. Для первого запуска задайте собственные данные администратора:

   ```powershell
   $env:CASESTORE_ADMIN_USER = "admin"
   $env:CASESTORE_ADMIN_PASSWORD = "ВашНадёжныйПароль123!"
   dotnet run
   ```

4. Откройте адрес, указанный в сообщении `Now listening on`, обычно `http://localhost:5000` или `https://localhost:5001`.

При первом запуске без переменных окружения создаётся демонстрационная учётная запись `admin` / `Admin123!`. Задайте переменные окружения **до первого запуска**: учётная запись администратора создаётся только при отсутствии администратора в хранилище. Если вы уже запустили сайт с демонстрационным паролем, измените пароль до публикации проекта.

## Возможности

- Покупатель может создать аккаунт, войти, добавить кейсы в корзину и сохранить демонстрационный заказ в личном кабинете. Оплата не подключена.
- Администратор открывает панель через личный кабинет и может добавлять, редактировать и удалять кейсы, цены и публикации; загружать фотографии кейсов и медиа для блога; менять название магазина и ссылку/текст кнопки WhatsApp.
- Для публикаций принимаются JPG, PNG, WebP, GIF, MP4 и WebM размером до 20 МБ. Можно также указать ссылку на изображение или видео.
- Переключатель темы запоминает выбор в браузере.

Проект предназначен для учебной демонстрации и локального запуска. Перед публикацией в интернете настройте HTTPS, резервное копирование хранилища и подходящий способ защиты и хранения данных.
